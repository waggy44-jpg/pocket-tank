# Pocket Tank

An installable virtual fish tank for your phone. A small advisor model gives
every fish its own decisions — how to eat, hide, explore, socialise and rest —
and the fish remember how you treat them.

A mobile version of [pocket-tank](https://github.com/mediacutlet/pocket-tank)
by StratoBuilds, which runs the same idea on a $40 ESP32 with a 14.3M-parameter
language model distilled from a 26B teacher. On a phone there is no room for
7.5 MB of weights, so the same interface — a one-line state description in, a
goal and an urgency out — is served by a weighted model over the same five
drives and three traits.

## Connect to Cloudflare

The app files are at the **repository root**, so Cloudflare picks them up with
no build command and no output directory:

| Setting | Value |
|---|---|
| Framework preset | None |
| Build command | *(leave empty)* |
| Build output directory | `/` |

Steps: **Create a repository** on GitHub, push this folder, then in Cloudflare
→ **Workers & Pages** → **Create** → **Pages** → **Connect to Git** and pick it.
You get an `https://<repo>.pages.dev` URL.

To deploy from the GitHub UI instead: **Settings → Pages → Deploy from a
branch** → branch `main`, folder `/ (root)`.

> The build output directory must be `/` (root). Cloudflare defaults to
> `/dist`, which does not exist here and will produce a blank site.

## Install on Android

Open the `https://…` URL in Chrome → **⋮ → Install app**. It installs as a
standalone app and works offline after the first load.

An `http://` or `file://` page cannot be installed — a secure origin is
required.

## How the tank works

**Feeding.** Tap the water line and pellets drop. A fish that is full may ignore
them; that is the model's decision, not a rule.

**Trust.** Hold a finger on the glass and the fish that trust you come over,
most trusting first. Tap hard three times and nearby fish scatter — and it
costs you their trust.

**Upkeep.** Seagrass grows on its own. A stroke that starts on a blade cuts it
at the height of your finger; a drag across the glass squeegees the algae off.
Let the tank overgrow and the fish get stressed.

**Tools.** Under a fish's card: the sponge only wipes glass, the scissors only
trim. With a tool in your hand the glass takes your strokes and nothing else.

**Growth and arrivals.** A new tank starts with two fry. Feed them and over
days they grow through juvenile, adult and elder. Care well and the two most
trusting adults circle low in the grass and a fry appears between them — but
only if a bed is tall enough to hide in.

**Sleep.** Double-tap the glass for lights out. The simulation keeps running at
a quarter speed, and wake it after hours and the school is ravenous.

**Unlocks.** Care earns sand dollars. The shop sells a sword plant, an
algae-grazing snail, a sea urchin that keeps the grass down, a swim-through
castle and coral. What you buy, you place yourself.

## Layout

```
index.html            the whole app (markup, styles, simulation, renderer)
sw.js                 service worker — app shell only, never user data
manifest.webmanifest  install metadata
netlify.toml, _redirects   headers and SPA rewrites (Netlify; harmless on Pages)
icon-*.png            launcher icons
tests/                the test suites — not deployed
parts/                the source parts index.html is assembled from
```

`index.html` is generated by concatenating `parts/p1.html`, `parts/logic.js`
and `parts/view.js`. Edit those, not the built file.

## Tests

```
node tests/app.test.js    # 155 simulation and game-rule assertions
node tests/app.smoke.js   # 94 render, wiring and PWA assertions
```

Both must pass before a deploy. The logic suite isolates the `LOGIC` block from
`index.html` in a `vm` and asserts behaviour; the smoke suite mounts the whole
inline script against a stub DOM and records real canvas geometry.
